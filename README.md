# 앨범태그

## 웹앱으로 먼저 시작하기

가장 쉬운 첫 버전은 [index.html](index.html)를 더블클릭해 웹 브라우저로 여는 것입니다.
회원가입이나 설치가 필요 없고, 입력한 앨범과 태그는 **현재 브라우저**에 저장됩니다.
상단 `백업` 버튼으로 데이터를 JSON 파일로 내려받아 보관할 수 있고, `복원`으로 다시 불러올 수 있습니다.

웹앱 파일은 `index.html`, `web/style.css`, `web/app.js`입니다. 안드로이드 버전은 이후 필요할 때 이어서 사용할 수 있도록 `app/` 폴더에 보관되어 있습니다.

갤럭시의 기존 사진 앨범을 그대로 유지하면서, **앨범 단위로 여러 태그를 붙여
교차 탐색**할 수 있는 안드로이드 앱입니다.

예를 들어 `2308 제주 여행` 앨범에 `여자친구`, `가족`, `여행`, `제주` 태그를
동시에 붙일 수 있습니다. 사진 파일이나 삼성 갤러리의 앨범 구성은 변경하지 않습니다.

## 현재 구현된 기능

- 갤럭시의 사진 앨범과 대표 이미지 불러오기
- 앨범 사진 그리드와 전체 화면 사진 보기
- 전체 화면에서 좌우 스와이프, 두 손가락 확대·축소 및 확대 영역 이동
- 촬영 날짜·현재 사진 번호 표시, 화면 탭으로 메뉴 숨기기
- 앨범별 태그 여러 개 추가·삭제
- 기존 태그를 탭 한 번으로 재사용
- 앨범명과 태그 통합 검색
- 여러 태그를 `모두 포함(AND)` 또는 `하나라도 포함(OR)`으로 필터
- 태그가 없는 앨범만 모아 보는 `미분류` 필터
- 기존 태그 이름을 바꾸고 연결된 모든 앨범에 일괄 반영
- 기존 태그를 모든 앨범에서 안전하게 삭제
- 태그를 `학창시절`, `취미`, `여행`, `함께한 사람` 같은 그룹으로 정리
- 태그 그룹 생성·수정·삭제 및 그룹별 필터 표시
- 여러 앨범을 선택해 기존 또는 새 태그를 한 번에 추가
- 앨범을 길게 눌러 바로 다중 선택 모드 시작
- 태그 데이터는 앱 내부에만 저장

## 처음 실행하기: 갤럭시에서 직접 써 보기

이 프로젝트는 Python이 아니라 안드로이드 표준 언어인 **Kotlin**으로 작성되어
있습니다. 코드를 몰라도 아래 순서대로 실행할 수 있습니다.

1. [Android Studio](https://developer.android.com/studio/install.html)를 PC에 설치합니다. 설치 과정의 `Setup Wizard`에서 추천 SDK 항목을 모두 설치하세요.
2. Android Studio를 열고 **Open**을 누릅니다.
3. 이 `README.md`가 들어 있는 프로젝트 폴더를 선택합니다.
4. 오른쪽 아래의 Gradle 동기화와 다운로드가 끝날 때까지 기다립니다.
5. 갤럭시에서 `설정 → 휴대전화 정보 → 소프트웨어 정보`로 들어가
   `빌드번호`를 7번 누릅니다.
6. `설정 → 개발자 옵션`에서 `USB 디버깅`을 켭니다.
7. USB 케이블로 휴대폰을 연결하고 휴대폰에 표시되는 허용 창에서 허용합니다.
8. Android Studio 상단 기기 목록에서 갤럭시를 선택하고 ▶ 실행 버튼을 누릅니다. 처음 실행할 때는 앱 빌드에 시간이 조금 걸립니다.
9. 휴대폰에서 앱의 사진 접근 요청을 허용합니다.

## APK 파일로 내 휴대폰에 설치하기

PC와 연결하지 않고 설치할 APK를 만들려면 Android Studio에서 다음을 누르세요.

1. 상단 메뉴 `Build → Build Bundle(s) / APK(s) → Build APK(s)`를 선택합니다.
2. 빌드가 끝난 알림의 `locate`를 누릅니다.
3. 생성된 `app-debug.apk` 파일을 갤럭시로 전송해 열고 설치합니다.

처음에는 이 방법이 가장 쉽습니다. Google Play에 올릴 때만 `Build → Generate Signed Bundle / APK`를 선택해 서명 키를 만들고, `Android App Bundle (.aab)`을 생성하면 됩니다. 서명 키 파일과 비밀번호는 절대 잃어버리지 마세요.

## GitHub에 코드 백업하기

GitHub은 사진·태그 데이터를 보관하는 곳이 아니라, **앱 코드의 백업과 변경 이력**을 보관하는 곳입니다. 초보자에게는 명령어보다 GitHub Desktop이 편합니다.

1. [GitHub Desktop](https://desktop.github.com/)을 설치하고 GitHub 계정으로 로그인합니다.
2. `File → Add local repository`를 누르고 이 프로젝트 폴더를 선택합니다.
3. 왼쪽 `Changes`에서 전체 파일이 선택되어 있는지 확인합니다.
4. 아래 요약 칸에 `첫 앨범태그 앱`이라고 쓰고 `Commit to main`을 누릅니다.
5. 상단 `Publish repository`를 누릅니다.
6. 처음에는 `Keep this code private`를 켜고 Publish하세요. 나중에 공개 여부는 바꿀 수 있습니다.

## 데이터 관련 주의

- 태그는 앱의 내부 저장소에 보관됩니다.
- 앱을 삭제하면 태그도 함께 삭제됩니다. 삭제하거나 휴대폰을 바꾸기 전에는 앱 상단의 `백업`으로 태그 파일을 저장하세요.
- 새 휴대폰에서 사진을 옮긴 뒤 앱 상단 `복원`으로 백업 파일을 선택하면 태그를 되살릴 수 있습니다. 같은 앨범 폴더 구조를 유지하는 것이 좋습니다.
- 원본 사진의 EXIF 정보나 삼성 갤러리 앨범은 수정하지 않습니다.
- 다음 버전에서는 태그 JSON 내보내기/불러오기를 추가해 백업할 수 있습니다.

```text
app/src/main/java/com/albumtags/app/
├── MainActivity.kt       화면과 사용자 동작
├── AlbumViewModel.kt     화면 상태와 필터 로직
├── AlbumRepository.kt    갤러리 조회와 태그 저장
└── Models.kt             앨범·태그 데이터 모델
```
